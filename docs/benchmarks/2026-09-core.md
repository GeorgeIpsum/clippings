# Core benchmark: 2026-09-23

Manual speed and parity check against ripgrep on the tilliX monorepo, per Plan 12
Step 6. Not a CI step. `hyperfine` was not installed on this machine, so timing
used `/usr/bin/time -p`: one untimed warm-up run per command, then three timed
runs, reporting the median of the three.

## Machine

- CPU: Apple M4 Pro, 14 cores (`sysctl -n machdep.cpu.brand_string hw.ncpu`)
- OS: macOS (Darwin 24.6.0)
- rustc/cargo: 1.96.1
- ripgrep: 15.1.0
- clippings: 0.1.0 (`cargo build --release`)
- Benchmark repo: `~/tilli/tilliX` (read-only; not modified)

## Timing (three warm runs after one warm-up; median reported)

| Set     | Command                                                                 | Runs (s)         | Median (s) |
| ------- | ------------------------------------------------------------------------ | ----------------- | ---------- |
| default | `clippings scan --json --config tags.json $T`                            | 0.02, 0.02, 0.02   | 0.02       |
| default | `rg -c --max-columns=1000 -e "$R" $T`                                    | 0.02, 0.02, 0.02   | 0.02       |
| wide    | `clippings scan --json --hidden --no-ignore --config wide.json $T`       | 0.19, 0.19, 0.17   | 0.19       |
| wide    | `rg -c --max-columns=1000 --hidden --no-ignore -g '!node_modules' -g '!.turbo' -g '!.next' -g '!.git' -e "$R" $T` | 0.12, 0.12, 0.16 | 0.12       |

## Result vs the 1.25x budget

- default set: clippings/ripgrep = 0.02 / 0.02 = **1.0x** — within budget.
- wide set: clippings/ripgrep = 0.19 / 0.12 = **~1.58x** — **exceeds the 1.25x
  budget.** This is reported plainly per the task instructions; no code was
  tuned to hide it. A second round of timing (not tabulated above) reproduced
  the same pattern (clippings medians around 0.17-0.19s vs ripgrep's
  0.12-0.17s on the wide set), so this is not a one-off measurement fluke.
  The default set stayed at parity across repeats. Root-causing the wide-set
  gap (hidden/no-ignore walking, or the built-in excludes glob path) is left
  to a follow-up; Plan 4's `clippings bench` command should make this
  reproducible and trackable over time.
